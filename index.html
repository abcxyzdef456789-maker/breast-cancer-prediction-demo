02 / MODEL WORKFLOW

From data to prediction

  1. 01
    Dataset Ingestion569 labeled records loaded from UCI Wisconsin Diagnostic repository.
  2. 02
    Feature EngineeringExtract 5 primary nuclear features; encode Benign as 0 and Malignant as 1.
  3. 03
    Ensemble TrainingTrain 300 decision trees via bagging; each tree learns unique feature splits.
  4. 04
    Stratified Evaluation114 unseen test records evaluated with Precision, Recall, and ROC-AUC.
  5. 05
    Consensus InferenceLive prediction computed by majority voting across all 300 decision trees.
